# Memory storage

**Store:** Long-term decisions, prefs, corrections, lessons, architecture—as **`t|id|s|w|r` lines** per `cogo-memory-format.md` (one concept per line).

**Skip:** Ephemeral tasks, verbose logs, duplicates, filler, secrets.

**Rules:** Short `s`; update lines sharing the same `id` instead of duplicating; reinforce repeats with one refreshed line.
